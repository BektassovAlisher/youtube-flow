# 🎙️ VideoFlow — AI Podcast Creator

**VideoFlow** — мультиагентная система на базе LangGraph, которая превращает учебные материалы — видео с YouTube и других площадок, подкасты, статьи по ссылке, PDF и вставленный текст — в конспекты и подкасты. Система извлекает текст, отсеивает необучающий контент, пишет подробный конспект со ссылками на места в материале (таймкоды или абзацы), сценарий диалога двух ведущих, озвучивает его и отвечает на вопросы через RAG (Retrieval-Augmented Generation).

## ✨ Возможности

| Функция | Описание |
|---|---|
| 🎬 **Видео** | Субтитры на русском, английском или казахском, а если их нет — на любом языке видео; без субтитров речь распознаётся через Groq Whisper |
| 🎧 **Другие площадки и подкасты** | Vimeo, Rutube, VK Видео, OK, Дзен, TED, Twitch, Dailymotion, SoundCloud, Apple Podcasts, Mixcloud и прямые ссылки на mp3/mp4: субтитры площадки, а без них — распознавание речи |
| 📰 **Статьи по ссылке** | Основной текст страницы без меню, рекламы и комментариев (trafilatura), с заголовками разделов, автором и обложкой; защита от запросов во внутреннюю сеть |
| 📋 **Вставленный текст и файлы** | Глава, лекция, заметки — вставляются в поле на главной или загружаются файлом (PDF, TXT, Markdown); тот же текст второй раз открывается из базы |
| 📍 **Ссылки на места** | В видео и подкастах — таймкоды `[MM:SS]` (встроенный плеер или оригинал на нужной секунде), в статье — абзацы `[¶N]`, которые открывают оригинал на нужном месте (`#:~:text=`), во вставленном тексте и PDF — абзац во вкладке «Текст» |
| 🔍 **Классификация контента** | ИИ пропускает учебные видео и статьи и судит по началу, середине и концу; вставленный текст не проверяется; отклонённое можно всё равно обработать |
| 📝 **Конспект** | Разделы с таймкодами, глоссарий и главные выводы; пишется у вас на глазах (потоково) и сохраняется сразу, до сценария |
| 🧠 **Проверь себя** | Вопросы для самопроверки карточками: ответ скрыт, пока его не откроешь, строится по транскрипту и кэшируется |
| 🔑 **Ключевые термины** | 10–15 терминов всей лекции — по оглавлению и выделенным понятиям конспекта |
| 🎙️ **Сценарий подкаста** | Диалог двух ведущих (Алекс и Марина), каждую версию проверяет редактор-критик |
| 🔊 **Аудио** | Две озвучки ElevenLabs, реплики озвучиваются параллельно и склеиваются без перекодирования (128 кбит/с) |
| 💬 **Вопросы по видео** | Гибридный поиск (векторы + BM25 со стеммингом), потоковый ответ со ссылками на моменты видео, уточняющие вопросы |
| ▶️ **Встроенный плеер** | Таймкоды запускают видео прямо на странице; при прокрутке плеер остаётся в углу |
| 🎯 **Рекомендации** | Онлайн-курсы и книги по теме — поиск Tavily по сайтам курсов и книжным магазинам |
| ⚙️ **Фоновая обработка** | Работа идёт на сервере: вкладку можно закрыть или обновить, одинаковые запросы не дублируются, прерванная обработка продолжается после перезапуска |
| 💾 **Мгновенный кэш** | Видео хранятся бессрочно; повторная ссылка на то же видео в любом формате отдаётся из базы без запросов к YouTube и LLM |
| 🔐 **Доступ** | Необязательный пароль приложения, токен API и почасовые лимиты на дорогие операции |
| 🌓 **Веб-интерфейс** | Next.js с серверным рендерингом, библиотека с поиском, экспорт конспекта в Markdown, тёмная и светлая тема |

## 🏗️ Архитектура

```
┌─────────────────┐     ┌──────────────────────┐     ┌─────────────────┐
│   Next.js (web) │────▶│    FastAPI (API)     │────▶│ Пул фоновых     │
│   (порт 3000)   │◀────│    (порт 8000)       │◀────│ задач: LangGraph│
└─────────────────┘     └──────────┬───────────┘     │ и озвучка       │
        ▲  события (NDJSON)        │                 └────────┬────────┘
        └──────────────────────────┤                          │
                      ┌────────────┼────────────┐             │
                 ┌────▼─────┐ ┌────▼───┐  ┌─────▼────┐ ┌──────▼───────┐
                 │PostgreSQL│ │ChromaDB│  │ElevenLabs│ │ LLM: Gemini  │
                 │ (данные) │ │(Вектор)│  │ (Аудио)  │ │ Whisper: Groq│
                 └──────────┘ └────────┘  └──────────┘ └──────────────┘
```

- Запрос на обработку возвращается сразу: работа идёт в пуле фоновых задач (`MAX_CONCURRENT_JOBS`), по одной задаче на видео. Повторный запрос того же видео присоединяется к уже идущей задаче.
- Страница видео подписывается на `/videos/{id}/events` и получает шаги, текст конспекта по мере написания и прогресс озвучки. Перезагрузка страницы просто подписывается заново.
- Каждый шаг сразу сохраняет результат в PostgreSQL, а уже сделанное пропускает. Поэтому сбой на сценарии не теряет конспект, а прерванная перезапуском обработка продолжается с того же места.
- Браузер обращается только к Next.js: запросы `/api/*` проксируются в FastAPI, поэтому CORS не нужен, адрес API задаётся переменной `API_URL`, а токен API не попадает в браузер.

### Виды материалов

| Вид | Откуда текст | Место в материале | Ссылка на место |
|---|---|---|---|
| `youtube` | субтитры или Whisper | `[MM:SS]` | момент во встроенном плеере |
| `media` | yt-dlp: субтитры площадки или Whisper; файл по прямой ссылке — Whisper | `[MM:SS]` | файл играет на странице; на площадке — ссылка на секунду (Vimeo `#t=`, Rutube и Twitch `?t=`, Dailymotion `?start=`) |
| `article` | страница по ссылке, trafilatura | `[¶N]` — номер абзаца | оригинал, прокрученный к абзацу (`#:~:text=`) |
| `text` | вставлен на главной или загружен файлом (PDF — по страницам) | `[¶N]` | абзац во вкладке «Текст» |

Все виды хранятся в одной таблице `videos` (колонка `kind`) и проходят один и тот же граф; отличаются только получение текста, промпты и ссылки на места. Идентификатор записи с другой площадки — `m-` + хэш ссылки, статьи — `a-` + хэш ссылки без меток отслеживания, вставленного текста или файла — `t-` + хэш текста. Какие ссылки считать видео или аудио, решает список площадок: у yt-dlp есть экстракторы и для новостных сайтов, а их статьи должны оставаться статьями.

### Граф агентов (LangGraph)

```
START → load → transcript → classify ─┬─▶ reject → END              (не учебный материал)
                                      │
                                      └─▶ start_pipeline ─┬─▶ summarize → keywords ─┬─▶ END (сценарий уже есть)
                                                          │                         │
                                                          │                         └─▶ script ⇄ critic → save_script → END
                                                          │                              (повтор, макс. 2)
                                                          └─▶ index → END            (векторный индекс для вопросов)
```

`load` читает из базы то, что уже сделано для видео; остальные узлы сохраняют свой результат и пропускают сохранённое. Озвучка — отдельная фоновая задача, запускается по кнопке.

## 🛠️ Технологический стек

| Компонент | Технология |
|---|---|
| **Оркестрация агентов** | LangGraph (StateGraph), потоковые события узлов (`get_stream_writer`) |
| **LLM** | Google Gemini 3.1 Flash Lite — все текстовые задачи: конспект, сценарий, ответы, классификатор, термины и критик (короткие проверки возвращают JSON). С `CHECKS_PROVIDER=groq` классификатор, термины и критик уходят в Groq `openai/gpt-oss-20b` и `gpt-oss-120b` |
| **Распознавание речи** | Groq Whisper (`whisper-large-v3-turbo`) + yt-dlp и ffmpeg — для видео без субтитров |
| **Статьи** | trafilatura — основной текст, заголовки и метаданные страницы |
| **Документы** | pypdf — текст PDF по страницам; TXT и Markdown в любой кодировке |
| **Другие площадки** | yt-dlp — метаданные, субтитры и звук записи |
| **Векторная БД** | ChromaDB + `paraphrase-multilingual-MiniLM-L12-v2` через fastembed (ONNX Runtime, без PyTorch) |
| **Гибридный поиск** | Векторный поиск + BM25 со стеммингом Snowball для русского и английского + Reciprocal Rank Fusion |
| **Генерация аудио** | ElevenLabs API (`eleven_multilingual_v2`), склейка MP3 по фреймам |
| **Веб-поиск** | Tavily Search API |
| **База данных** | PostgreSQL (SQLAlchemy ORM), миграции схемы при старте |
| **API** | FastAPI |
| **Интерфейс** | Next.js 16 (App Router), React 19, react-markdown |
| **Контейнеризация** | Docker + Docker Compose (healthcheck'и, модель эмбеддингов внутри образа) |

## 🚀 Установка и запуск

### Docker

```bash
git clone https://github.com/BektassovAlisher/youtube-flow.git
cd youtube-flow
cp .env.example .env   # заполните ключи API
docker compose up -d --build
```

После запуска:
- **Интерфейс:** [http://localhost:3000](http://localhost:3000)
- **API:** [http://localhost:8000](http://localhost:8000)
- **Swagger:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **PostgreSQL:** `localhost:5435`

API ждёт готовности Postgres (healthcheck), интерфейс — готовности API. Модель эмбеддингов скачивается при сборке образа, а не при каждом запуске.

Остановка: `docker compose down` (с удалением данных — `docker compose down -v`).

### Локальный запуск

Нужны Python 3.11+, Node.js 20+, PostgreSQL 15+ и ffmpeg (только для распознавания речи у видео без субтитров).

1. **Виртуальное окружение и зависимости:**
```bash
python -m venv venv
source venv/bin/activate  # macOS/Linux
pip install -r backend/requirements.txt
```

2. **Переменные окружения:**
```bash
cp .env.example .env
```

3. **База данных** — своя (`createdb lecture_agent`) или из Docker: `docker compose up -d db` (порт `5435`, как в `.env.example`). Таблицы создаются и обновляются при старте API.

4. **API:**
```bash
cd backend/app
uvicorn api.api:app --host 0.0.0.0 --port 8000 --reload
```

5. **Интерфейс** (в отдельном терминале):
```bash
cd frontend
npm install
npm run dev
```
По умолчанию он обращается к API на `http://127.0.0.1:8000`; адрес меняется переменной `API_URL`.

6. **Откройте** [http://localhost:3000](http://localhost:3000)

### Тесты

Тесты не ходят в сеть и не требуют ключей: SQLite, фейковые LLM, YouTube, ElevenLabs и модель эмбеддингов.

```bash
pip install -r backend/requirements-dev.txt
cd backend && python -m pytest
```

Проверка типов интерфейса: `cd frontend && npm run typecheck`.

| Переменная | Описание | Обязательно |

| `DB_PASSWORD` | Пароль PostgreSQL (для Docker) | 🐳 |
| `API_URL` | Адрес FastAPI для интерфейса (в Docker — `http://api:8000`) | — |
| `API_TOKEN` | Токен для POST/DELETE в API; интерфейс подставляет его сам | рекомендуется |
| `APP_PASSWORD` | Пароль приложения для обработки, вопросов, аудио и удаления | — |

| `ALLOW_PRIVATE_URLS` | Разрешить статьи из внутренней сети (например, корпоративная вики); по умолчанию `false` | — |
| `MAX_CONCURRENT_JOBS` | Сколько видео обрабатывается одновременно (по умолчанию 3) | — |
| `TTS_CONCURRENCY` | Параллельные запросы к ElevenLabs (по умолчанию 2) | — |
| `WHISPER_FALLBACK` | Распознавать речь у видео без субтитров (по умолчанию `true`) | — |
| `WHISPER_MAX_MINUTES` | Максимальная длина видео для распознавания (по умолчанию 180; на бесплатном плане Groq — 120, см. [ниже](#-скорость-и-бесплатные-лимиты)) | — |
| `GEMINI_MODEL` | Модель Gemini (по умолчанию `gemini-3.1-flash-lite`) | — |
| `GEMINI_THINKING_LEVEL` | Сколько модель Gemini 3 думает перед ответом: `minimal`, `low`, `medium`, `high`; по умолчанию — как задано у модели | — |
| `CHECKS_PROVIDER` | Кто выполняет классификатор, термины и критика: `gemini` (по умолчанию) или `groq` | — |
| `LIMIT_VIDEOS_PER_HOUR`, `LIMIT_AUDIO_PER_HOUR`, `LIMIT_QUESTIONS_PER_HOUR` | Почасовые лимиты на клиента (20 / 10 / 120, `0` — без лимита) | — |

Без ключей API тоже запускается: библиотека и готовые конспекты открываются, а шаг, которому нужен ключ, сообщит, какого ключа не хватает.

## 🛡️ Доступ и лимиты

- **`API_TOKEN`** — все POST и DELETE в API требуют заголовок `Authorization: Bearer <API_TOKEN>`; чтение открыто. Интерфейс добавляет токен сам на сервере, в браузер он не попадает.
- **`APP_PASSWORD`** — читать конспекты можно без входа, а обработка новых видео, вопросы, озвучка и удаление требуют входа по паролю (подписанная httpOnly-cookie на 30 дней).
- **Лимиты** — новые материалы, озвучка и ответы модели ограничены по количеству в час на клиента; ответы из кэша и уже обработанные материалы в лимит не входят.
- **Ссылки на статьи** — сервер открывает только публичные адреса: localhost, частные сети, адреса Docker и облачные метаданные отклоняются, каждый редирект проверяется заново, размер страницы ограничен 5 МБ.

## ⏱️ Скорость и бесплатные лимиты

Все текстовые задачи выполняет Gemini; Groq нужен только для распознавания речи.

- **Запросы к Gemini на один материал:** 5 — классификатор, конспект, термины, сценарий и критик; ещё 2, если критик вернул сценарий на доработку. Вставленный текст не проверяется классификатором. Каждый новый вопрос — ещё один запрос; ответы из кэша и уже обработанные материалы запросов не тратят.
- **Лимит запросов в минуту:** при ответе 429 запрос повторяется с растущими паузами (до 6 попыток, около полуминуты в сумме), поэтому короткий упор в лимит лишь замедляет обработку. Если запросов Gemini в сутки не хватает, `CHECKS_PROVIDER=groq` отдаёт классификатор, термины и критика моделям Groq — тогда на материал уходит 2–3 запроса к Gemini.
- **Распознавание речи** нужно только записям без субтитров. Бесплатный план Groq ограничивает его часами аудио в час и в сутки, поэтому запись длиннее этого часового лимита упрётся в него на середине — на бесплатном плане ставьте `WHISPER_MAX_MINUTES=120`.
- **Озвучка** тратит символы ElevenLabs (модель `eleven_multilingual_v2`: один символ сценария — один кредит).

Точные лимиты вашего проекта показывают Google AI Studio и консоль Groq.

**Сколько занимает каждый шаг** — видно в логе API: для каждого материала есть строка «готово за N с» с секундой, на которой закончился каждый шаг (`transcript`, `classify`, `summarize`, `index`, `keywords`, `script`, `critic`), для вопросов — «ответ за … первые слова через …», для озвучки — «аудио готово за …».

```bash
docker compose logs api | grep -E "готово за|ответ за"
```

## 🤖 Мультиагентный пайплайн

Пайплайн построен на **LangGraph StateGraph**. Каждый узел сохраняет результат и пропускает уже сделанное.

### 1. 💾 Load
Достаёт из базы всё, что уже сделано для видео: транскрипт, вердикт классификатора, конспект, термины, сценарий.

### 2. 🎬 Transcript
**Видео:** субтитры через `youtube-transcript-api` — сначала русский, английский или казахский, иначе любой язык видео. Если субтитров нет совсем — yt-dlp скачивает звук, ffmpeg режет его на куски по 10 минут, Groq Whisper распознаёт их параллельно. Название и канал приходят из oEmbed одновременно с субтитрами.

**Запись с другой площадки:** yt-dlp получает название, автора, длительность и обложку; если у записи есть субтитры (сначала русские, английские или казахские) — они и становятся текстом, иначе звук распознаётся через Whisper. Файл по прямой ссылке (mp3, m4a, mp4…) скачивается с той же проверкой адресов, что и статьи (до 500 МБ), и распознаётся. Плейлисты, каналы и прямые трансляции отклоняются с объяснением.

**Статья:** страница скачивается с проверкой адреса и редиректов, trafilatura оставляет основной текст с заголовками разделов, а сайт, автор и обложка берутся из метаданных. Текст делится на пронумерованные абзацы; если страница отдаёт текст только через JavaScript или за подпиской, пользователь получает совет вставить текст вручную.

**Вставленный текст** приходит вместе с запросом: абзацы разделяются пустыми строками, `# Заголовок` начинает раздел. **Загруженный PDF** читается постранично (разделы «Страница N»), переносы слов на концах строк склеиваются; PDF с паролем и сканы без текстового слоя отклоняются с объяснением. TXT и Markdown — как вставленный текст, в любой кодировке (в том числе старой cp1251).

Текст сохраняется, чтобы шаги можно было повторить без повторной загрузки.

### 3. 🔍 Classify
Классифицирует видео (`educational`, `entertainment`, `news`, `music`, `gaming`, `random`) по названию, каналу и фрагментам из начала, середины и конца. Вердикт сохраняется: повторная обработка его не пересматривает. Для статей отдельный, более мягкий промпт: подходят объяснения, руководства, разборы и лонгриды, а не реклама, короткие новости и заглушки. Пропускает материал с уверенностью ≥ 0.6; отклонённое можно обработать принудительно. Вставленный текст не проверяется — его добавили намеренно.

### 4. 📝 Summarize
Подробный конспект с разделами, глоссарием и вопросами для самопроверки. У разделов видео — таймкоды, у разделов текста — номер абзаца `[¶N]`, с которого раздел начинается. Текст передаётся на страницу по мере написания и сохраняется сразу — пользователь читает конспект, пока пишется сценарий.

### 5. 🔑 Keywords
10–15 терминов всей лекции: модель выбирает их из оглавления и выделенных понятий конспекта. Если модель недоступна, берутся самые частые выделенные понятия.

### 6. 🧠 Index
Индексирует транскрипт для вопросов параллельно с конспектом. Сбой здесь не останавливает обработку — индекс достроится при первом вопросе.

### 7. 🎙️ Script и ✅ Critic
Сценарий диалога двух ведущих (Алекс — новичок, Марина — эксперт). Критик читает сценарий целиком, проверяет формат и использование терминов и может вернуть сценарий на доработку (максимум 2 попытки).

### 8. 🔊 Audio
Отдельная фоновая задача по кнопке: реплики озвучиваются параллельно (`TTS_CONCURRENCY`) с повтором при перегрузке ElevenLabs, склеиваются по MP3-фреймам без перекодирования. Если хотя бы одна реплика не озвучилась, неполное аудио не сохраняется.

### 9. 🎯 Recommend
Курсы и книги через Tavily Search по сайтам курсов и книжным магазинам — по запросу, результат кэшируется.

## 💬 RAG система (Вопрос-Ответ)

**Гибридный поиск** для точных ответов:

1. **Семантический поиск** — ChromaDB с эмбеддингами `paraphrase-multilingual-MiniLM-L12-v2` (ONNX через fastembed)
2. **Лексический поиск** — BM25 со стеммингом Snowball и стоп-словами: «нейронные сети» находит «нейронная сеть»; индекс BM25 кэшируется в памяти
3. **Reciprocal Rank Fusion** — объединение результатов, фрагменты идут в порядке видео

Для статей и текстов фрагменты помечены номерами абзацев `¶N`, и ответ ссылается на них так же, как на таймкоды у видео.

В контекст попадает и краткое содержание из конспекта, поэтому вопросы обо всём видео («о чём оно», «главные выводы») отвечаются по всему видео, а не по пяти фрагментам. Последние вопросы диалога передаются вместе с новым — уточнения вроде «а подробнее?» понимают, о чём речь. Ответы без истории (вопросы «Проверь себя», подсказки) кэшируются в базе.

## 🖥️ Интерфейс

Интерфейс написан на **Next.js** (`frontend/`). Направление дизайна и причина каждого решения записаны в [`frontend/DESIGN.md`](frontend/DESIGN.md), разбор прежней версии по правилам [antislop](https://github.com/miqdadbadjuber/anti-slop) лежит в [`docs/design-audit.md`](docs/design-audit.md).

Дизайн устроен как печатный конспект: бумага и чернила, один акцент (жёлтый маркер на главном), таймкоды и номера абзацев на полях. Заголовки набраны Geologica, текст и интерфейс Onest; оба шрифта сделаны с полноценной кириллицей. Анимации повторяют мотив маркера: он проводит черту под главным, под новой вкладкой и строкой под курсором.

### Создать
- Поле для ссылки на первом экране, переключатель «Ссылка / Текст или файл»: вставка текста с необязательным названием или загрузка PDF, TXT, MD
- На правом поле коротко описано, что произойдёт после нажатия
- После отправки сразу открывается страница материала: там видно, какой шаг идёт, и как пишется конспект
- Понятные ошибки: ссылка на плейлист или канал, нет субтитров, сайт за подпиской, YouTube блокирует сервер
- Отклонённые классификатором материалы показываются с причиной и кнопкой «Всё равно обработать»
- Недавние материалы списком, со ссылкой на библиотеку

### Библиотека
- Список с обложкой (кадр видео, обложка статьи или название сайта), типом материала, каналом или сайтом, языком, длительностью или временем чтения и датой
- Поиск по названию, каналу и сайту, страницы; материалы, которые ещё обрабатываются, отмечены

### Страница материала
- Вкладки: Конспект, (Текст), Проверь себя, Сценарий, Аудио, Рекомендации, Вопросы; активная вкладка сохраняется в адресе
- Таймкоды разделов стоят на левом поле, оглавление справа; маркером выделены только ключевые термины и определяемые понятия
- Конспект можно скачать в Markdown или пересоздать
- Таймкоды запускают видео во встроенном плеере; при прокрутке он остаётся в углу экрана
- У статьи «Открыть статью»; абзацы `¶N` в конспекте и ответах открывают оригинал на нужном месте
- Файл по прямой ссылке играет на странице, таймкоды его перематывают; у записей с других площадок таймкоды открывают оригинал на нужной секунде
- У вставленного текста вкладка «Текст»: номера абзацев на полях, клик по `¶N` открывает её и подсвечивает абзац
- Вкладки не теряют состояние: история вопросов, открытые ответы и найденные рекомендации остаются при переключении
- Ответы на вопросы приходят потоком; аудио играет сразу, не дожидаясь загрузки всего файла

Данные страниц загружаются на сервере и приходят сразу в HTML: без экрана загрузки и с сохранением прокрутки при перезагрузке.

### Темы и доступность
- Светлая «бумажная» и тёмная тема; при первом визите берётся тема системы, выбор сохраняется
- Весь текст проходит контраст WCAG AA в обеих темах, у всех полей видимые подписи, фокус с клавиатуры виден везде
- Движение отмечает события: маркер прорисовывается под терминами, вкладками и строками, содержимое вкладок мягко появляется, тема меняется плавно; с «уменьшить движение» в системе анимации отключаются
