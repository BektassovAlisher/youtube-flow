# VideoFlow

Конспекты, вопросы для самопроверки и подкасты из учебных материалов: видео с YouTube и других площадок, подкастов, статей по ссылке, PDF и вставленного текста.

Вставляете ссылку или текст, и система на LangGraph получает текст материала, проверяет, что он учебный, пишет подробный конспект со ссылками на места в оригинале (таймкоды или номера абзацев), выделяет термины, а по кнопке пишет сценарий подкаста на два голоса и озвучивает его. По материалу можно задавать вопросы: ответы строятся по самому тексту и ссылаются на нужные моменты.

## Возможности

**Откуда берётся текст**
- **YouTube:** субтитры на русском, английском или казахском, иначе на любом языке видео. Если субтитров нет, речь распознаёт Groq Whisper.
- **Другие площадки и подкасты:** Vimeo, Rutube, VK Видео, OK, Дзен, TED, Twitch, Dailymotion, SoundCloud, Apple Podcasts, Mixcloud и прямые ссылки на mp3 и mp4. Берутся субтитры площадки, без них работает распознавание речи.
- **Статьи по ссылке:** основной текст страницы без меню, рекламы и комментариев, с заголовками разделов, автором и обложкой. Адреса внутренней сети сервер не открывает.
- **Свой текст и файлы:** глава, лекция или заметки вставляются в поле на главной или загружаются файлом PDF, TXT или Markdown.

**Что получается**
- **Конспект:** разделы, определения, выводы и вопросы для самопроверки. Пишется у вас на глазах и сохраняется сразу.
- **Ссылки на места:** у видео и подкастов таймкоды (видео стартует во встроенном плеере), у статей номера абзацев (оригинал открывается на нужном месте), у своего текста и PDF абзац во вкладке «Текст».
- **Проверь себя:** вопросы из конспекта, ответ открывается по кнопке и строится по тексту материала.
- **Ключевые термины:** 10–15 главных понятий всей лекции.
- **Сценарий и аудио** (по кнопке): диалог двух ведущих (Алекс спрашивает, Марина объясняет) пишется у вас на глазах, редактор проверяет каждую версию. Потом сценарий можно озвучить двумя голосами ElevenLabs.
- **Вопросы по материалу:** гибридный поиск (векторы и BM25 со стеммингом), ответ потоком со ссылками на места, уточняющие вопросы.
- **Рекомендации:** онлайн-курсы и книги по теме через Tavily.

**Как работает**
- **Проверка материала:** клипы, реклама и пустые страницы отсеиваются, но их можно обработать вручную. Свой текст не проверяется.
- **Фоновая обработка:** вкладку можно закрыть или обновить, одинаковые запросы не дублируются, прерванная обработка продолжается после перезапуска с последнего шага.
- **Кэш:** обработанное хранится в базе, повторная ссылка на тот же материал открывается сразу.
- **Доступ:** необязательный пароль приложения, токен API и почасовые лимиты на дорогие операции.

## Как устроено

```
┌─────────────────┐     ┌──────────────────────┐     ┌─────────────────┐
│   Next.js (web) │────▶│    FastAPI (API)     │────▶│ Пул фоновых     │
│   (порт 3000)   │◀────│    (порт 8000)       │◀────│ задач: LangGraph│
└─────────────────┘     └──────────┬───────────┘     │ и озвучка       │
        ▲  события (NDJSON)        │                 └────────┬────────┘
        └──────────────────────────┤                          │
                      ┌────────────┼────────────┐             │
                 ┌────▼─────┐ ┌────▼───┐  ┌─────▼────┐ ┌──────▼───────┐
                 │PostgreSQL│ │ChromaDB│  │ElevenLabs│ │ LLM: Gemini  │
                 │ (данные) │ │(Вектор)│  │ (Аудио)  │ │ Whisper: Groq│
                 └──────────┘ └────────┘  └──────────┘ └──────────────┘
```

- Запрос на обработку возвращается сразу, работа идёт в пуле фоновых задач (`MAX_CONCURRENT_JOBS`), по одной задаче на материал. Повторный запрос того же материала присоединяется к уже идущей задаче.
- Страница материала подписывается на `/videos/{id}/events` и получает шаги, текст конспекта по мере написания и прогресс озвучки. Перезагрузка страницы просто подписывается заново.
- Каждый шаг сразу сохраняет результат в PostgreSQL и пропускает уже сделанное. Сбой на одном шаге не теряет сделанное раньше, а прерванная перезапуском обработка продолжается с того же места.
- Браузер обращается только к Next.js: запросы `/api/*` проксируются в FastAPI. CORS не нужен, адрес API задаётся переменной `API_URL`, токен API в браузер не попадает.

### Виды материалов

| Вид | Откуда текст | Место в материале | Куда ведёт ссылка |
|---|---|---|---|
| `youtube` | субтитры или Whisper | `[MM:SS]` | момент во встроенном плеере |
| `media` | yt-dlp: субтитры площадки или Whisper; файл по прямой ссылке через Whisper | `[MM:SS]` | файл играет на странице; на площадке ссылка на секунду (Vimeo `#t=`, Rutube и Twitch `?t=`, Dailymotion `?start=`) |
| `article` | страница по ссылке, trafilatura | номер абзаца | оригинал, прокрученный к абзацу (`#:~:text=`) |
| `text` | вставлен на главной или загружен файлом (PDF по страницам) | номер абзаца | абзац во вкладке «Текст» |

Все виды хранятся в одной таблице `videos` (колонка `kind`) и проходят один и тот же граф; отличаются получение текста, промпты и ссылки на места. В тексте конспекта модель ставит абзацы как `[¶N]`, а интерфейс показывает их как «абз. N». Идентификатор записи с другой площадки: `m-` и хэш ссылки, статьи: `a-` и хэш ссылки без меток отслеживания, своего текста или файла: `t-` и хэш текста.

### Граф агентов (LangGraph)

```
START → load → transcript → classify ─┬─▶ reject → END              (не учебный материал)
                                      │
                                      └─▶ start_pipeline ─┬─▶ summarize → keywords → END
                                                          │
                                                          └─▶ index → END            (векторный индекс для вопросов)

По кнопке «Написать сценарий», отдельный граф:

START → script ⇄ critic → save_script → END                     (повтор, макс. 2)
```

`load` читает из базы то, что уже сделано; остальные узлы сохраняют свой результат и пропускают сохранённое. Сценарий и озвучка запускаются отдельными фоновыми задачами по кнопке: обработка заканчивается на терминах и не тратит запросы на подкаст, который может быть не нужен.

## Технологии

| Часть | Что используется |
|---|---|
| Оркестрация | LangGraph (StateGraph), потоковые события узлов |
| Языковые модели | Google Gemini 3.1 Flash-Lite (`gemini-3.1-flash-lite`) для всех текстовых задач: конспект, сценарий, ответы, проверка материала, термины, критик (короткие проверки отвечают в JSON). Модель меняется переменной `GEMINI_MODEL`; по желанию можно задать запасную модель на случай перегрузки (`GEMINI_FALLBACK_MODEL`) |
| Распознавание речи | Groq Whisper (`whisper-large-v3-turbo`), yt-dlp и ffmpeg |
| Статьи и документы | trafilatura для страниц, pypdf для PDF по страницам; TXT и Markdown в любой кодировке |
| Поиск по материалу | ChromaDB и `paraphrase-multilingual-MiniLM-L12-v2` через fastembed (ONNX, без PyTorch), BM25 со стеммингом Snowball, Reciprocal Rank Fusion |
| Аудио | ElevenLabs (`eleven_multilingual_v2`), MP3 128 кбит/с склеивается по фреймам без перекодирования |
| Рекомендации | Tavily Search |
| База данных | PostgreSQL, SQLAlchemy 2.1 с драйвером psycopg 3, схема обновляется при старте |
| API | FastAPI |
| Интерфейс | Next.js 16 (App Router), React 19, react-markdown; шрифты Geologica и Onest |
| Запуск | Docker Compose: проверки готовности сервисов, модель эмбеддингов внутри образа |

## Установка и запуск

### Docker

```bash
git clone https://github.com/BektassovAlisher/youtube-flow.git
cd youtube-flow
cp .env.example .env   # впишите ключи API
docker compose up -d --build
```

После запуска:
- интерфейс: http://localhost:3000
- API: http://localhost:8000, документация Swagger: http://localhost:8000/docs
- PostgreSQL: `localhost:5435`

API ждёт готовности Postgres, интерфейс ждёт готовности API. Модель эмбеддингов скачивается при сборке образа, а не при каждом запуске.

Обновление до новой версии:

```bash
git pull && docker compose up --build -d
```

Остановка: `docker compose down`, с удалением данных: `docker compose down -v`.

### Без Docker

Нужны Python 3.11+, Node.js 20+, PostgreSQL 15+ и ffmpeg (только для распознавания речи).

```bash
python -m venv venv && source venv/bin/activate
pip install -r backend/requirements.txt
cp .env.example .env
```

База данных: своя (`createdb lecture_agent`) или из Docker: `docker compose up -d db` (порт `5435`, как в `.env.example`). Таблицы создаются и обновляются при старте API.

```bash
cd backend/app && uvicorn api.api:app --host 0.0.0.0 --port 8000 --reload
```

В отдельном терминале:

```bash
cd frontend && npm install && npm run dev
```

Интерфейс обращается к API на `http://127.0.0.1:8000`, адрес меняется переменной `API_URL`.

### Тесты

Тесты не ходят в сеть и не требуют ключей: SQLite, поддельные модели, YouTube, ElevenLabs и эмбеддинги.

```bash
pip install -r backend/requirements-dev.txt
cd backend && python -m pytest
```

Проверка типов интерфейса: `cd frontend && npm run typecheck`.

## Переменные окружения

Файл `.env` в корне проекта, шаблон в `.env.example`.

| Переменная | Описание | Нужна |
|---|---|---|
| `DATABASE_URL` | Подключение к PostgreSQL | да |
| `GOOGLE_API_KEY` | Ключ Google Gemini | да |
| `GROQ_API_KEY` | Ключ Groq: распознавание речи у записей без субтитров | для записей без субтитров |
| `ELEVENLABS_API_KEY` | Ключ ElevenLabs | для аудио |
| `TAVILY_API_KEY` | Ключ Tavily | для рекомендаций |
| `DB_PASSWORD` | Пароль PostgreSQL | для Docker |
| `API_URL` | Адрес FastAPI для интерфейса (в Docker `http://api:8000`) | нет |
| `API_TOKEN` | Токен для POST и DELETE в API; интерфейс подставляет его сам | рекомендуется |
| `APP_PASSWORD` | Пароль приложения для обработки, вопросов, аудио и удаления | нет |
| `SESSION_SECRET` | Ключ подписи cookie (по умолчанию выводится из пароля) | нет |
| `GEMINI_MODEL` | Модель Gemini (по умолчанию `gemini-3.1-flash-lite`) | нет |
| `GEMINI_FALLBACK_MODEL` | Запасная модель, когда основная перегружена (по умолчанию не задана) | нет |
| `GEMINI_THINKING_LEVEL` | Сколько модель думает перед ответом: `minimal`, `low`, `medium`, `high`. У `gemini-3.1-flash-lite` по умолчанию `minimal`, это самый быстрый вариант | нет |
| `LANGSMITH_TRACING`, `LANGSMITH_API_KEY`, `LANGSMITH_PROJECT` | Трассировка в LangSmith (см. [Метрики и LangSmith](#метрики-и-langsmith)) | нет |
| `WHISPER_FALLBACK` | Распознавать речь у записей без субтитров (по умолчанию `true`) | нет |
| `WHISPER_MAX_MINUTES` | Максимальная длина записи для распознавания (по умолчанию 180; на бесплатном плане Groq лучше 120) | нет |
| `YOUTUBE_PROXY_URL` | Прокси для YouTube, если он блокирует IP сервера | нет |
| `ALLOW_PRIVATE_URLS` | Разрешить статьи из внутренней сети (по умолчанию `false`) | нет |
| `MAX_CONCURRENT_JOBS` | Сколько материалов обрабатывается одновременно (по умолчанию 3) | нет |
| `TTS_CONCURRENCY` | Параллельные запросы к ElevenLabs (по умолчанию 2) | нет |
| `LIMIT_VIDEOS_PER_HOUR`, `LIMIT_AUDIO_PER_HOUR`, `LIMIT_QUESTIONS_PER_HOUR` | Почасовые лимиты на клиента (20, 10 и 120; `0` без лимита) | нет |

Без ключей приложение тоже запускается: библиотека и готовые конспекты открываются, а шаг, которому нужен ключ, сообщит, какого ключа не хватает.

## Доступ и лимиты

- **`API_TOKEN`:** все POST и DELETE в API требуют заголовок `Authorization: Bearer <API_TOKEN>`, чтение открыто. Интерфейс добавляет токен на сервере, в браузер он не попадает.
- **`APP_PASSWORD`:** читать конспекты можно без входа, а обработка, вопросы, озвучка и удаление требуют входа по паролю (подписанная httpOnly-cookie на 30 дней).
- **Лимиты:** новые материалы, озвучка и ответы модели ограничены числом в час на клиента; ответы из кэша и уже обработанные материалы в лимит не входят.
- **Ссылки на статьи:** сервер открывает только публичные адреса. Localhost, частные сети, адреса Docker и облачные метаданные отклоняются, каждый редирект проверяется заново, размер страницы до 5 МБ.

## Скорость и бесплатные лимиты

- **Запросы к Gemini на материал:** 3 (проверка, конспект, термины). Сценарий по кнопке добавляет ещё 2 (сценарист и критик) и ещё 2 на каждую доработку, если критик вернул сценарий. Свой текст не проверяется. Каждый новый вопрос даёт ещё один запрос; ответы из кэша запросов не тратят.
- **Упор в минутный лимит:** при ответе 429 запрос повторяется с растущими паузами (до 6 попыток, около полуминуты), поэтому обработка лишь замедляется.
- **Распознавание речи** нужно только записям без субтитров. Бесплатный план Groq ограничивает его часами аудио в час и в сутки, поэтому на нём лучше `WHISPER_MAX_MINUTES=120`.
- **Озвучка** тратит символы ElevenLabs: один символ сценария равен одному кредиту.

Точные лимиты вашего проекта показывают Google AI Studio и консоль Groq. Время каждого шага пишется в лог API:

```bash
docker compose logs api | grep -E "готово за|ответ за"
```

## Метрики и LangSmith

**Свои метрики.** Для каждого материала API сохраняет, как прошла обработка: общее время, время каждого шага, время до первых строк конспекта, токены на входе и выходе, модель и время озвучки. На странице материала под конспектом есть строка «Обработано за N с», по клику раскрывается таблица по шагам. Под каждым новым ответом на вопрос показано, за сколько он получен. Средние значения по всем материалам отдаёт `GET /stats`:

```bash
curl http://localhost:8000/stats
```

**LangSmith.** Трассировка включается тремя строками в `.env` (ключ берётся на smith.langchain.com):

```bash
LANGSMITH_TRACING=true
LANGSMITH_API_KEY="lsv2_..."
LANGSMITH_PROJECT="videoflow"
```

После перезапуска API каждая обработка видна в LangSmith одной трассой «VideoFlow: обработка материала» со всеми шагами графа и вызовами модели: промпты, ответы, время, токены и стоимость. Ответы на вопросы идут трассами «VideoFlow: ответ на вопрос». Найти трассу материала можно по метаданным `video_id`. Без этих переменных ничего никуда не отправляется. Для европейского региона LangSmith задайте ещё `LANGSMITH_ENDPOINT`.

## Пайплайн по шагам

1. **Load.** Достаёт из базы то, что уже сделано: текст, вердикт проверки, конспект, термины.
2. **Transcript.**
   - YouTube: субтитры (русские, английские или казахские, иначе любые). Без субтитров yt-dlp скачивает звук, ffmpeg режет его на куски по 10 минут, Whisper распознаёт их параллельно.
   - Другие площадки: yt-dlp берёт название, автора, длительность, обложку и субтитры площадки, без субтитров работает Whisper. Файл по прямой ссылке скачивается с той же проверкой адресов, что и статьи (до 500 МБ). Плейлисты, каналы и трансляции отклоняются с объяснением.
   - Статья: страница скачивается с проверкой адреса и редиректов, trafilatura оставляет основной текст. Если текст доступен только через JavaScript или за подпиской, приложение советует вставить его вручную.
   - Свой текст: абзацы разделяются пустыми строками, `# Заголовок` начинает раздел. PDF читается по страницам, переносы слов склеиваются; PDF с паролем и сканы без текста отклоняются с объяснением.
3. **Classify.** Категория (`educational`, `entertainment`, `news`, `music`, `gaming`, `random`) по названию, каналу и фрагментам из начала, середины и конца. Если на YouTube автор отнёс видео к категории «Образование» или «Наука и техника», модель не спрашивается: категория берётся со страницы видео, пока скачиваются субтитры. Другая категория передаётся модели как подсказка. Материал проходит при уверенности от 0.6, отклонённое можно обработать вручную. Вердикт сохраняется.
4. **Summarize.** Подробный конспект с разделами, определениями, выводами и вопросами для самопроверки. Передаётся на страницу по мере написания и сохраняется сразу.
5. **Keywords.** 10–15 терминов из оглавления и выделенных понятий конспекта.
6. **Index.** Индекс для вопросов строится параллельно с конспектом; сбой здесь не останавливает обработку, индекс достроится при первом вопросе.
7. **Script и Critic** (по кнопке). Сценарий диалога двух ведущих, передаётся на страницу по мере написания. Критик читает его целиком и может вернуть на доработку (до 2 раз).
8. **Audio** (по кнопке). Реплики озвучиваются параллельно с повтором при перегрузке ElevenLabs. Неполное аудио не сохраняется.
9. **Recommend** (по кнопке). Курсы и книги через Tavily, результат кэшируется.

## Ответы на вопросы (RAG)

1. **Смысловой поиск:** ChromaDB с эмбеддингами `paraphrase-multilingual-MiniLM-L12-v2`.
2. **Поиск по словам:** BM25 со стеммингом Snowball и стоп-словами, так что «нейронные сети» находит «нейронная сеть».
3. **Слияние:** Reciprocal Rank Fusion, фрагменты идут в порядке материала.

В контекст попадает и краткое содержание из конспекта, поэтому вопросы обо всём материале («о чём он», «главные выводы») отвечаются по всему материалу. Последние вопросы диалога передаются вместе с новым, и уточнения вроде «а подробнее?» понимают, о чём речь. Ответ начинается сразу с сути, без приветствий. Ответы без истории (вопросы «Проверь себя», подсказки) кэшируются.

## Интерфейс

Дизайн устроен как печатный конспект: бумага и чернила, один акцент (жёлтый маркер на главном), таймкоды и номера абзацев на полях, рабочие блоки на светлых подложках с тонкой обводкой. Заголовки набраны Geologica, текст и интерфейс Onest. Направление и причины решений записаны в [`frontend/DESIGN.md`](frontend/DESIGN.md), разбор прежней версии по правилам [antislop](https://github.com/miqdadbadjuber/anti-slop) лежит в [`docs/design-audit.md`](docs/design-audit.md).

- **Главная:** поле для ссылки или текста и загрузка файла, рядом пояснение, что будет после нажатия, ниже недавние материалы. Понятные ошибки и кнопка «Всё равно обработать» для отклонённого.
- **Библиотека:** список с обложкой, типом, каналом или сайтом, языком, длительностью и датой; поиск и страницы.
- **Страница материала:** вкладки Конспект, Текст (для своего текста), Проверь себя, Сценарий, Аудио, Рекомендации, Вопросы; активная вкладка сохраняется в адресе. Конспект пишется сразу на своём месте и не прыгает после завершения, его можно скачать в Markdown или пересоздать. Таймкоды запускают видео во встроенном плеере, при прокрутке он остаётся в углу. Вкладки не теряют состояние при переключении.
- **Темы и доступность:** светлая и тёмная тема (по умолчанию как в системе), контраст текста по WCAG AA в обеих, видимые подписи полей и фокус с клавиатуры. Анимации отмечают события (маркер прорисовывается под терминами, вкладками и строками) и отключаются, если в системе включено «уменьшить движение».
